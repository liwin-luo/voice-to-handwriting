# Print a handwritten letter and a matching envelope for three people

Free, no signup, about ten minutes. Three short calls this week become three US Letter notes and three #10 envelopes. You print them, add postage, and mail them yourself.

The page fills one thank-you for each name and lays the matching address on an envelope. The writing is Patrick Hand, the English page's default handwriting font, with small shifts so the lines are not perfectly even. It is a font. This site does not print, stamp, or mail anything.

## The two PDFs

**Download letters PDF** saved `handwritten-letters.pdf`: 3 pages, each 8.5 × 11 inches. **Download envelopes PDF** saved `handwritten-envelopes.pdf`: 3 pages, each 9.5 × 4.125 inches. The envelope page is the envelope itself, so a printer has to accept a #10, or you print at actual size and cut. I checked those page sizes in the files. I did not open Priya's page in a reader, and I did not feed a #10 through a printer.

Print the letters at actual size, one page per sheet of US Letter. Fold, stamp, and mail them.

## When one person needs different words

The letter box starts as the note you picked. I left the thank-you as it was, so these three letters share it. You can replace that text. `name` in braces becomes the person, and `from` in braces becomes the first line of the return address. On this same machine I swapped the box for one line that greeted the name and signed the return-address line. The preview read Hello Avery Chen, from Jordan Lee. I put the thank-you back before the pictures above.

A `message` cell replaces the box for that row only. I left that column off. The list stops at 30 people. If you want help with the wording, that is [handwritten thank-you notes](/blog/handwritten-thank-you-notes). One card, with no list, belongs in the [template library](/templates).

English pages use US Letter and a #10. Other languages on this site use A4 and a DL envelope. These letters are a handwriting font. They should not be passed off as ink from a pen.

## Questions that come up

**Will the site mail these?** No. You get two PDFs. Postage and the mailbox are yours.

**Is the list a spreadsheet upload?** Paste it, or use Excel template and Import Excel. The first row is `name,street,city,region,postal`. One person per row. A `.csv` file imports the same way.

**Can the note be longer?** Yes, until it fills the page. This thank-you is short on purpose, which is why the lower half of the sheet is empty.
