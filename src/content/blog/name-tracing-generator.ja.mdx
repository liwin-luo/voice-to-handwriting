# 名前なぞり書きジェネレーター:60秒で個別ワークシートが完成

子どもの名前は、たいてい**自分で書けるようになる初めての言葉**です。自分のものだからこそ大切で、教室に貼られるどのワークシートよりもたくさん練習されます。画一的な文字ドリルではなく名前のなぞり書きが効くのは、このためです。

「編集できる名前なぞり書き」とうたう印刷素材のほとんどは、実際には編集できない PDF か、無料版にウォーターマークを入れるアプリです。ここでは、無料の**名前なぞり書きジェネレーター**で**個別のなぞり書きワークシート**を作る方法を紹介します——登録不要、ウォーターマークなし、印刷用の PDF がそのまま手に入ります。

## 3ステップで作る

1. [名前なぞり書きジェネレーター](/name-tracing)を開く;
2. 1行に1名ずつ入力——クラス全員分を用意するなら「Emma」「Liam」「Olivia」と続けて;
3. フォントを選び、行の高さを調整して、**PDFをダウンロード**を押す。

たったこれだけ。ページには3ラインの書字帯が並びます。子どもの名前が濃い色の**お手本行**として1回印刷され、その下に**薄いグレー**のなぞり行が繰り返されます。

## ワークシートの見た目

| 要素 | 役割 |
| --- | --- |
| 上の線(薄い) | 天井——*b・k・T* のように背の高い文字が触れる線 |
| 破線の中央線 | ウエスト——小文字の本体が終わる位置を示す |
| 実線のベースライン | 床——すべての文字がこの線に乗る |
| 濃いお手本行 | 名前の正しい形を1サイクルに1回示す |
| 薄いグレーの行 | なぞる対象——鉛筆でグレーの上をなぞる |

**行の高さスライダー(60–120px)**の調整こそが、4歳児が使えるワークシートと、子どもが挫折するワークシートを分けます。大きめから始めてください。未就学児は100–110px、年長さんは80–90px、小学1年生の復習ではもっと小さく。

## フォントの選び方

- **Patrick Hand** — すっきりした印刷体の字形。先生が文字を見本として示すときに最も近い書き味;
- **Kalam / Indie Flower** — やや丸みがあって親しみやすい。書く気が起きない子向け;
- **Caveat / Cedarville Cursive** — 小学2〜3年生の筆記体の名前練習に(そう、筆記体は米国の多くの州の学習指標に戻りつつあります)。

正直に言うと、なぞる文字は**ベタ塗りの薄いグレー**で、矢印付きの破線アウトラインではありません。ほとんどの子は形をなぞるだけで十分です。番号付きの筆順ガイドが必要な子には、このジェネレーターは対応していません。文字の書き方カードと組み合わせてください。

## 教室の裏ワザ:クラス全員を1ファイルに

児童の名前を1行に1人ずつ入力します。ジェネレーターは**全員の名前を順に使ってページを埋めます**——各名前には、濃いお手本行1行と、それに続く薄いグレーのなぞり行が割り当てられます。1人ずつ印刷して本人の行に印を付けるのも、ページを細長く切って朝のドリルにするのもおすすめです。

名前以外の幼稚園での書字練習には、[無料で印刷できる3ライン書字用紙](/printable-paper)を組み合わせてください。同じ3ライン方式の白紙版で、残りのアルファベットの練習に使えます。

## 実測済み、制限も正直に

- 最近のブラウザならどれでも動作します。PDF は US **Letter** サイズ(8.5×11インチ)で、A4 の場合は100%の倍率で印刷して余白をカットするか、多少の余白を想定してください;
- フォントはオープンソースの手書きフォントであり、Zaner-Bloser や D'Nealian など市販教材のスタイルそのものではありません;
- アップロードは一切ありません。ワークシートはブラウザ内で描画され、名前がサーバーに保存されることはありません;
- 無料、アカウント不要、ウォーターマークなし。

## よくある質問

- **この名前なぞり書きジェネレーターは本当に無料?** はい。フォントはオープンソースで、すべてブラウザ内で動作し、登録も不要です。
- **点線の文字でなぞり書きシートは作れる?** なぞる文字は破線ではなく薄いグレーです。鉛筆で上からなぞる設計です。
- **筆記体の名前なぞりシートの作り方は?** フォントメニューで Dancing Script か Cedarville Cursive を選びます。[筆記体練習ワークシート](/blog/cursive-practice-worksheets)も参照してください。
- **名前なぞり書きは何歳向け?** 目安は3〜6歳です。まず名だけを大きな行で練習し、書けるようになったら姓を追加します。
