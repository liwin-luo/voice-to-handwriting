# 如何写一张别人会好好留着的手写感谢卡

发条消息说句「谢谢」就够了。而一张**手写感谢卡**传达的是：「你值得我花上二十分钟和一张邮票。」正因为如此，感谢卡挺过了每一次技术变革——也正因为如此，婚礼、迎婴派对、求职面试和贵重礼物之后，礼节上依然期待着一张卡片。

如果你的借口是「不知道写什么」，或者「我的字惨不忍睹」，这两个问题都有救。下面是四段式公式、可以直接抄用的范例，以及一个给「怕写字的人」准备的打印方案。

## 四段式公式（适用于任何场合）

1. **用名字称呼对方** —— 写「亲爱的姑姑」，而不是「嗨」；
2. **具体点出礼物** —— 「那口 Le Creuset 铸铁锅」比「你贴心的礼物」更有分量；
3. **说出它的意义或你的用法** —— 这是别人会记住的部分：「周日的汤，从这口锅开始升级」；
4. **往前看，收好结尾** —— 「等你们来家里喝汤。再次感谢——爱你的小雅。」

四句话。只要填满这四个格子，你就会写感谢卡了。

## 可以直接抄用的范例

| 场合 | 真正起作用的那一句话 |
| --- | --- |
| 婚礼礼物 | 「这套餐具我们惦记了三年，现在终于摆进了自己家——今年每一顿请客的饭，都要先谢谢你们。」 |
| 求职面试 | 「听你们聊团队怎么做产品上线的那一段，让我确定这就是我想要的岗位——非常期待能加入。」 |
| 老师 | 「孩子不爱举手的那阵子，是您先注意到，也是您帮他找了回来。这个学年过去很久以后，我们仍会记得。」 |
| 迎婴派对 | 「那条手织的小毯子已经是哄睡首选——看上去倒像是宝宝自己挑的。」 |
| 做东的家宴 | 「你家的餐桌让我们舍不得让那个晚上结束。下一次，轮到我们家。」 |
| 邻居 / 帮忙 | 「我们还没开口，人已经到了。好邻居，说的就是这样的。」 |

不想对着一张空白卡片发呆？[感谢信模板](/templates/thank-you-letter) 会把一段完整的示例文字放进编辑器，纸张和墨色都已经搭配好。

## 「可是我的字太丑了」

三个诚实的办法，按推荐顺序排列：

1. **把速度放慢三成。** 大多数「字丑」其实是「写得太急」——字写大一点、间距放宽一点、词与词之间停顿三秒，看上去就工整多了；
2. **用横格纸或三线纸当轨道。** [可打印的横格纸](/printable-paper) 能守住基线；也可以把打印好的纸垫在更讲究的信纸下面当参考；
3. **用真正的手写字体来排版。** 把想说的话粘进[手写工具](/)，选 **Caveat**（随性）或 **Cedarville Cursive**（优雅），然后打印——字句还是你的，而且比打印体的卡片暖得多。不过**求职面试**还是要自己写：这张卡的意义就在那份亲手的心意。

## 时间上的经验法则

- **面试**：24 小时内，一小段话，提到谈话中的一个具体瞬间；
- **婚礼**：3 个月内（计时从收到礼物开始，而不是送出礼物）；
- **其他场合**：一周内最理想；迟到的手写卡，也胜过及时的短信。

## 大家还在问

- **面试之后还要寄手写感谢卡吗？** 要寄——多数招聘负责人都表示它有分量，而且几乎没有人因为寄了一张而失分。
- **感谢卡写多长合适？** 四句话正好写满一张标准卡片；除非你有故事要讲，否则不必更长。
- **礼物是现金的话写什么？** 感谢那份心意，再说说打算：「这份厚礼会直接存进『新自行车基金』。」
- **用打印的手写字体做感谢卡可以吗？** 日常道谢可以——文字本身就能带来温度。面试和正式场合，还是请亲手写。
