# Bubble letters for a short display name

Peach2 is six characters. On October 26, 2026 I typed it into [FancyFont](https://fancyfont.tools/cute-font-generator/) in desktop Chrome on macOS. Free, no signup. The page says the conversion stays in the browser, and the counter read 6 / 120. Seven rows came back. Five of them are bubble letters for a display name, with one decoration at most. A script line and a circled line sit under those.

![Peach2 typed into FancyFont. The counter reads 6/120, the preview-size slider sits at the left, transparent background is off, and the bubble rows show a heart, a bow, a flower, and soft brackets.](/blog/bubble-letters-peach2.png)

Paste a bubble row when the name has to live in a profile field. When that same name has to be a card or a picture, export a handwriting font. The two outputs do different jobs.

## What each row did to the letters

This is not a font file you install. The bubble row uses negative squared capitals, so the lowercase e, a, c, and h in Peach2 became the same capital squares as P. The 2 became ❷. Circled letters kept the capital P and the lowercase e, a, c, and h, and the 2 became ②. The script row is mathematical script, and its 2 stayed the digit I typed. Decorations sit only on the bubble rows, one pair, with a space on each side of the name.

Accented letters and emoji stay as typed. I also entered José and a heart emoji. The counter read 7 / 120 for that string, because the emoji counts as two. The é and the emoji showed up unchanged on every row, with the Latin letters converted around them.

A long run of the letter a hit the cap. The counter read 120 / 120, and the bubble row was 120 letters.

## One mark, then stop

The page treats coquette, kawaii, and soft as names for rows on this same screen. The bow row is the coquette one. The heart and the flower are the softer ones. There is no second generator to open.

Keep the name short. Peach2 is already busy once a heart sits on both sides. A full sentence in the same squares is hard to read, and the page itself points at captions rather than full sentences. Style the name. Leave the rest of the bio in ordinary type.

If a bow or the soft brackets come back as empty boxes on the phone you will post from, copy the heart row. That is the page's own fallback. The heart is a symbol most phones already draw.

## Where those letters can sit

The page says the characters work in most Instagram, TikTok, and Discord display names and bios, and that a username limited to plain letters will reject them. It also says an Instagram username allows letters, digits, periods, and underscores. Put the bubble name in the display name. Leave the @handle in plain characters, so someone can still type it and a search can still find it.

I did not paste Peach2 into those apps. A row that looks right in desktop Chrome can still be a box on an older phone. Check the field you will publish.

A screen reader may announce the squares one by one, or call them symbols. Keep a phone number or a date in ordinary digits.

## The same name on paper

A place card or a story image needs a real font. Open the [cursive font generator](/cursive-font-generator), replace the sample Merry & bright with the name, and leave the starting settings if they already fit: size 44, Black ink, white background. Each row offers PNG, SVG, and PDF. PNG follows the background you picked. A PDF is filled white when that background is transparent. I did not download a file in this pass.

A whole sentence of flowing script, the kind you paste into a bio rather than a short name, belongs on the [cursive text generator](/cursive-text-generator). That page does not draw these squares or this bow.

## Three answers

**Is a cute font a file I install?** No. The result on FancyFont is Unicode characters. That is why a text field can hold it.

**Is coquette a different tool from kawaii?** No. On this page the bow row is the coquette one, and the heart or the flower is the softer one.

**Can these letters be an Instagram username?** The page says no. Use them in the display name or the bio.
