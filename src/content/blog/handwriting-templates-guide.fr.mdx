# Bibliothèque de modèles : six scénarios, choisissez et écrivez

« Ouvrir l'outil → page blanche → aucune idée. » La bibliothèque de modèles existe pour ce moment précis. Chaque modèle = un texte adapté au scénario + un style manuscrit assorti (police, papier, encre, alignement). Choisissez, changez quelques mots, exportez.

## Les six scénarios

| Modèle | Idéal pour | Style |
| --- | --- | --- |
| Lettre d'amour | Ce qu'on n'ose pas dire | Cursive × papier lettre × bleu noir |
| Excuses | Des excuses sincères | Régulière × papier lettre × noir |
| Remerciement | Ceux qui ont aidé | Cursive × papier lettre × bleu noir |
| Anniversaire | Le post d'anniversaire | Régulière × uni × cinabre, centré |
| Fête des maîtres | Merci au mentor | Régulière × papier lettre × noir |
| Nouvel An | Le post de fin d'année | Grande régulière × uni × cinabre, centré |

![Bibliothèque de modèles](/blog/templates.png)

## Pourquoi les modèles incluent le style

Dans nos tests, le bon texte avec le mauvais style donnait toujours une image « décalée » : des excuses en cursive paraissent légères, un anniversaire en noir perd la fête. Chaque modèle préconfigure donc police, papier, encre, alignement et réalisme — vous ne changez que le destinataire et la signature.

## Comment utiliser

1. Choisissez un scénario dans la [bibliothèque](/templates);
2. L'aperçu montre l'effet manuscrit — cliquez « Utiliser ce modèle »;
3. Le texte arrive librement éditable dans l'éditeur; les styles restent ajustables;
4. Exportez PNG pour envoyer ou PDF pour imprimer.

## Testé, avec des limites honnêtes

Toutes les étapes ont été testées sur Chrome de bureau (macOS, octobre 2026). L'écriture est un rendu de style manuscrit, pas de la vraie écriture — l'usurpation est interdite (voir les conditions). Nous ne collectons ni texte ni audio. Référence : [MDN · Web Speech API](https://developer.mozilla.org/docs/Web/API/Web_Speech_API).
