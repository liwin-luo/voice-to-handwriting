# Practice one character in the grid, one row a night

Practice one character in the grid, then stop. The box on the [writing practice page](/writing-practice) repeats whatever you type until every square is full. A sentence turns into a checkerboard of every character in it. Tonight is one character.

Type 口. Leave the script on 中文 田字格. The font stays LXGW WenKai. The guide stays on cross. The fill stays on Trace. Cell size stays at 84. The page is A4. In the print dialog, choose actual size.

## What the default page contains

At cell size 84 the sheet is eight squares across and twelve down. Trace prints the top row dark and every square under it as a pale copy of the same character. Eight dark copies, then the pale ones. The cross in each square is a dashed line through the center. It marks where the character sits. It is not a stroke-order diagram, and there is no numbered arrow.

Spaces are removed. A second character shares the squares with the first, so the top row is no longer one shape. That is why a proverb stays out of the box until the single character is easy to place.

The box starts empty. The hint text is not printed until you type it. An empty page is only the grid.

| Script button | Font it selects | Guide it selects |
| --- | --- | --- |
| 中文 田字格 | LXGW WenKai | Cross, the dashed center line |
| 日本語 原稿紙風 | Klee One | Inner box |
| 한국어 원고지风 | Nanum Pen Script | A dot in the center |

The Japanese and Korean grids follow the idea of manuscript paper. They are not a publisher's exact school sheet. Changing the script resets the font and the guide. You can pick a different guide after that.

## Cover the dark row

A 5- or 6-year-old who is learning this script traces one pale row with a finger, then with a pencil, and stops. A 7-year-old covers the dark row with a strip of paper and copies into the pale squares. 口 is one closed shape. A character with more strokes, such as 永, can wait until the square itself is familiar.

Empty cells look like the independent step. On the Chinese script they drop the cross. The inner box and the center dot remain if those guides are selected. For 田字格, stay on Trace and cover the dark row, so the cross is still there.

Nothing you type is uploaded. The download is one A4 page. Latin names and spelling words belong on [name tracing](/name-tracing), on three-line paper, not in these squares.

## If the character will not sit in the square

Move the cell size up, as far as 110, and keep the box to one character. A larger square is still the same character. Two characters in the box is how the row becomes a pattern. One row a night is the dose. The rest of the page can be tomorrow, the same character or the next one.
