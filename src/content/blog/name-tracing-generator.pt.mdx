# Gerador de traçado de nomes: atividades personalizadas em 60 segundos

O próprio nome costuma ser **a primeira palavra que a criança aprende a escrever** — é dela, tem valor, e é mais praticada do que qualquer outra coisa no mural de atividades. É por isso que o traçado de nomes funciona quando os exercícios genéricos de letras não funcionam.

A maioria das atividades de traçado de nome "editáveis" que você encontra por aí são PDFs que não dá para editar de verdade, ou apps que colocam marca-d'água na versão gratuita. Aqui vai como criar uma **atividade de traçado personalizada com um gerador gratuito** — sem cadastro, sem marca-d'água, com um PDF pronto para imprimir.

## Faça a sua em três passos

1. Abra o [gerador de traçado de nomes](/name-tracing);
2. Digite um nome por linha — "Emma", depois "Liam", depois "Olivia" se você está preparando material para a turma inteira;
3. Escolha a fonte, ajuste a altura das linhas e clique em **Baixar PDF**.

Só isso. A página se preenche com faixas de escrita de três linhas: o nome da criança impresso em escuro como **linha de exemplo** e, abaixo, repetido em **cinza-claro** para traçar por cima.

## Como fica a atividade

| Elemento | O que faz |
| --- | --- |
| Linha de cima (clara) | Teto — letras altas como *b, k, T* encostam nela |
| Linha do meio tracejada | Cintura — marca onde termina o corpo das minúsculas |
| Linha de base contínua | Chão — toda letra se apoia nela |
| Linha de exemplo em escuro | Mostra o nome formado corretamente, uma vez por ciclo |
| Linhas cinza-claro | O alvo do traçado — o lápis passa por cima do cinza |

O **controle deslizante de altura das linhas (60–120px)** é o que separa uma atividade que uma criança de 4 anos consegue usar de uma que só a frustra. Comece grande: 100–110px na pré-escola, 80–90px no jardim de infância, menor para a revisão do 1.º ano.

## Escolhendo a fonte

- **Patrick Hand** — formas de letra limpas em estilo de imprensa, o mais próximo de como os professores escrevem as letras no quadro;
- **Kalam / Indie Flower** — um pouco mais arredondadas e simpáticas, boas para crianças que resistem à escrita;
- **Caveat / Cedarville Cursive** — para treinar o nome em cursiva no 2.º e 3.º ano (sim, a cursiva está voltando aos currículos de vários estados dos EUA).

Uma nota honesta: as letras para traçar são **cinza-claro sólido**, não contornos tracejados com setas indicando o traço. Para a maioria das crianças isso resolve — elas traçam a forma. Se o seu filho precisa de setas numeradas de trajetória do traço, este gerador não oferece; combine com cartões de formação de letras.

## Truque de sala de aula: a turma inteira em um arquivo

Digite o nome de cada aluno em uma linha própria. O gerador **percorre todos os nomes para preencher a página** — cada nome ganha uma linha de exemplo em escuro seguida de linhas cinza-claro para traçar. Imprima uma cópia por aluno e destaque a linha dele, ou corte a página em tiras para a atividade da manhã.

Para treinar caligrafia além dos nomes no jardim de infância, combine com [papel de caligrafia de três linhas grátis para imprimir](/printable-paper) — o mesmo sistema de três linhas, em branco, para o resto do alfabeto.

## Testado, com limitações honestas

- Funciona em qualquer navegador moderno; o PDF sai no tamanho **Letter** (8,5×11 polegadas) — no A4, imprima em escala de 100% e apare, ou conte com margens um pouco diferentes;
- As fontes são de escrita à mão de código aberto, não o estilo exato de nenhum método comercial (Zaner-Bloser, D'Nealian etc.);
- Nada é enviado para servidores — a atividade é renderizada no seu navegador e nenhum nome fica armazenado;
- Grátis, sem conta, sem marca-d'água.

## Perguntas frequentes

- **Este gerador de traçado de nomes é realmente grátis?** Sim — as fontes são de código aberto, tudo roda no seu navegador e não há cadastro.
- **Dá para fazer atividades com letras pontilhadas?** As letras para traçar são cinza-claro em vez de contornos tracejados — feitas para traçar por cima com lápis.
- **Como faço uma ficha de traçado de nome em cursiva?** Escolha Dancing Script ou Cedarville Cursive no menu de fontes — veja [atividades de prática de cursiva](/blog/cursive-practice-worksheets).
- **Para que idade serve o traçado de nomes?** Normalmente de 3 a 6 anos: comece só com o primeiro nome em linhas grandes e acrescente o sobrenome quando o primeiro já sair consistente.
