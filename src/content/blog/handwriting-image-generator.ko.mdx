# 손글씨 이미지 생성기: 타이핑 대신 말하세요

"손글씨 생성기"를 검색하면 도구가 수두룩하지만, 거의 모두 **타이핑**이 먼저입니다. 200자 카피를 작은 텍스트 상자에 입력해 본 적이 있다면 그 번거로움을 아실 거예요.

Voice to Handwriting는 몇 안 되는 **음성 입력** 지원 도구입니다. 말하면 바로 손글씨 이미지가 됩니다. 잘 쓰는 법을 알려드릴게요.

## 왜 음성 입력이 맞나

- **빠름**: 타이핑보다 3배 이상, 긴 문장일수록 유리
- **자연스러움**: 구어체가 손글씨의 온기와 잘 어울림
- **수정 쉬움**: 결과는 편집 가능한 텍스트 상자에 담깁니다

## 설정 가이드

| 설정 | 추천 | 효과 |
| --- | --- | --- |
| 글꼴 | 마산정 / 룽창 | 해서는 단정, 행서는 유려 |
| 리얼리즘 | 60% 전후 | 실제 글씨의 흔들림 재현 |
| 용지 | 줄선 / 모눈 | 공책 감성 즉시 완성 |
| 잉크 | 청흑색 | 일상 펜에 가장 가까움 |

이후 **"필적 바꾸기"**를 누르면 결정론적 랜덤 생성이 완전히 새로운 변주를 만듭니다. 몇 번 시도하고 마음에 드는 것을 저장하세요.

## PNG vs PDF

- **PNG**: 메신저, SNS 게시용
- **PDF**: 인쇄용(카드·편지) — 여러 페이지는 자동 분页됩니다

## FAQ

**글자 흔들림이 전부 똑같나요?** 아니요. 글자마다 독립적인 랜덤 생성이며, 텍스트를 수정해도 다른 글자의 필적은 바뀌지 않습니다.

**모바일에서 되나요?** 페이지는 열리지만 음성 인식은 데스크톱 Chrome / Edge가 최적입니다. 모바일에서는 입력해 주세요.

**무료인가요?** 네, 가입도 필요 없습니다.
