# 英文连笔怎么写：真正有效的初学者指南

大多数英文连笔教程只丢给你一张字母表，然后祝你好运。这恰恰跳过了让连笔真正开窍的两个关键：**始终一致的倾斜度**，以及**共享笔画的字母**。先练笔画，26个字母就只是六七种小变化，而不是26个孤立的问题。

这是手写老师们的教学顺序，为成年自学者做了调整。练习过程中，随时把任意单词输入[英文连笔生成器](/cursive)，打印出来描摹——整套方法不花一分钱。

## 从四种笔画开始，而不是从字母开始

每个小写连笔字母都由四个动作构成：

1. **上挑弧**——进入大多数字母时走的「上坡斜道」，像一个浅浅的 *u* 形；
2. **下行笔**——主要的竖直下拉，一笔流畅完成（你的倾斜度就体现在这里）；
3. **拱顶弧**——收笔时的「小山」拱形，像浅浅的 *n* 峰；
4. **连接线**——基线上的小尾巴，负责交接给下一个字母。

先只练笔画，把每一种笔画各填满几行——斜坡、下拉、小山——再动手写任何一个字母。如果十分钟后你的下行笔全都朝同一侧倾斜，最难的部分你已经完成了。

## 按字母家族学习，而不是按字母表顺序

| 家族 | 字母 | 共同动作 |
| --- | --- | --- |
| 椭圆族 | a, c, d, g, o, q | 先写一个拱顶弧，再进入圆形的「c」形 |
| 波浪族 | i, t, u, w, e | 上下起伏的锯齿形笔画 |
| 隆起族 | n, m, h, b, r, p | 立在基线上的一个（或两个）拱形 |
| 环族 | l, f, k, j | 下行笔上高高的（或向下俯冲的）环 |
| 特殊族 | s, v, x, y, z | 各自独立的形状——留到最后再练 |

按家族连续练习：一次坐下来练 *c, a, d, g, o, q*，你就会发现它们都是同一个圆，只是出口不同。而按 a→b→c 的字母表顺序练，你学到的只是26个互不相关的形状。

## 连接规则（这正是「连笔」的由来）

- 小写字母通过收笔的小尾巴**在基线处**连接；
- 有四个字母收笔位置偏高，连接起来很别扭：**o, b, v, w**。让它们单独站立，或让下一个字母重新起笔——和它们的连接线较劲，是初学者的第一大挫败感；
- 保持**同一种倾斜度**（0°～5°左右都可以）。倾斜度混用，即使每个字母都正确，整体看起来也是乱的；
- **词与词的间距**要能放下一个笔尖——连笔字很快就会挤在一起。

## 30天初学者计划

- **第1周**：四种笔画 + 椭圆族。每天五分钟热身笔画，然后一天两个字母；
- **第2周**：波浪族 + 隆起族。开始写真实的小单词：*it, in, at, an, on*；
- **第3周**：环族 + 特殊族，然后随机顺序写完26个小写字母。每天写自己的名字和所在的城市；
- **第4周**：大写字母（它们的连接没那么严格——把它们当成印刷体字母的漂亮表亲就行），然后写完整句子。

## 大家还在问

- **学英文连笔最简单的方法是什么？** 先练笔画，再按字母家族学（而不是按字母表顺序），最后练连接——每天练10～15分钟，好过周末一次练几小时。
- **学会英文连笔要多久？** 大多数成年人每天短时间练习，3～4周内就能写出可读的连笔；流畅、不假思索的连笔需要一两个月。
- **先学小写还是大写连笔？** 小写——你写的内容95%都是小写。大写字母没那么统一，可以等几周再学。
- **所有连笔字母都相互连接吗？** 不是——*o, b, v* 和 *w* 收笔位置偏高，大多数书写风格都允许下一个字母在它们之后重新起笔。
