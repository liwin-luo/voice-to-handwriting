# 녹음을 무료로 손글씨 노트로: 브라우저 로컬 방식 실측

회의 녹음, 수업 내용, 이동 중 음성 메모를 공유할 만한 손글씨 노트로 만들려면 예전에는 '변환 → 복사 → 레이아웃 → 내보내기' 4단계가 필요했습니다.

이제 한 단계입니다: **오디오 파일을 올리면 손글씨 문서가 됩니다**. 무료이고 오디오는 기기를 벗어나지 않습니다.

## 3가지 루트 비교

| 루트 | 비용 | 프라이버시 | 적합한 경우 |
| --- | --- | --- | --- |
| 브라우저 내 Whisper (채택) | 0 | 오디오 기기 내 | 일상 노트, 민감한 내용 |
| 클라우드 ASR | 종량제 또는 무료 한도 | 업로드됨 | 초장시간·속도 중시 |
| 폰 받아쓰기 | 0 | 방식에 따라 | 일회성 짧은 메모 |

## 실측 결과

환경: macOS + Chrome, WASM 경로, 빠른 모델.

- 입력: TTS로 합성한 중국어 음성(약 5초)
- 출력: "你好,這是一段測試語音,用來驗證音頻轉寫功能。" — 내용 완전 일치(번체자 출력은 base 모델의 알려진 경향으로, 고품질 모델에서 개선)

최초 모델 로드는 약 1분, 이후 브라우저가 캐시합니다.

![툴바의 오디오 가져오기](/blog/toolbar.png)

## 사용 방법

1. [도구](/)에서 "오디오 파일 가져오기" 클릭(mp3 / wav / m4a 지원)
2. 진행 상황 대기(최초 모델 다운로드 포함)
3. 변환 텍스트가 에디터에 들어옵니다. 수정 후 내보내기

## 솔직한 한계

base 모델은 강한 억양과 소음에 취약하고, 30분 이상 오디오는 시간이 걸립니다. 중요한 내용은 고품질 모델 + 직접 확인을 권합니다. Safari의 일부 코덱 미지원으로 데스크톱 Chrome / Edge를 권장합니다.

## 실측과 솔직한 한계

데스크톱 Chrome(macOS, 2026년 10월)에서 직접 테스트했고, 스크린샷은 실제 화면입니다. 음성 인식은 브라우저 벤더가 제공하며 환경에 따라 품질이 달라집니다. 중요한 내용은 확인 후 사용하세요. 텍스트·오디오는 수집하지 않습니다([개인정보 처리방침](/privacy)). 참고: [MDN · Web Speech API](https://developer.mozilla.org/docs/Web/API/Web_Speech_API).
