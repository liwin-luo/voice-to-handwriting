# 手書き風画像ジェネレーター:入力せずに話すだけ

「手書き風ジェネレーター」で検索すると大量のツールが出てきますが、ほぼすべて**入力**が必要。200 字のコピーを小さなテキストボックスに打ち込んだ経験があれば、その面倒くささは分かるはず。

「Voice to Handwriting」は数少ない**音声入力**対応のツールです。話すだけで手書き風画像になります。使いこなし方を解説します。

## なぜ音声入力が向いているのか

- **速い**:入力の 3 倍以上。長文ほど効果的
- **自然**:話し言葉のほうが手書きの温度感に合う
- **修正も簡単**:結果は編集可能なテキストボックスに入る

## 設定の目安

| 設定 | 推奨 | 効果 |
| --- | --- | --- |
| フォント | 馬善政 / 龍蔵 | 楷書は整って、行書は流麗に |
| リアリティ | 60% 前後 | 本物の字の揺らぎを再現 |
| 用紙 | 横罫線 / 方眼 | ノート感がすぐ出る |
| インク | 藍黒 | 普段使いのペンに近い |

その後「筆跡を変える」を押すと、決定論的ランダム生成がまったく新しい変化を出します。数回試して気に入ったものを保存しましょう。

## PNG と PDF の使い分け

- **PNG**:メッセージアプリや SNS 投稿に
- **PDF**:印刷(カード・手紙)に。複数ページは自動で改ページ

## FAQ

**字の揺れは全部同じ?** いいえ。一文字ごとに独立したランダム生成で、文字を編集しても他の字の筆跡は変わりません。

**モバイルで使える?** ページは開けますが、音声認識はデスクトップ Chrome / Edge が最適。スマホでは入力してください。

**無料?** 無料です。登録も不要です。
