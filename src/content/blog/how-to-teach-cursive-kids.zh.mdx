# 如何在家教孩子写英文连笔字（每次10分钟的小课）

也许你所在州的学校已经不教连笔字了。也许他们只在三年级风风火火地教一个星期，就翻篇了。无论哪种情况，如果你想让孩子真正学会写英文连笔字，家就是如今的主阵地——好消息是：**每周三次、每次10分钟的专注练习，胜过任何字帖马拉松**。

这是小学老师沿用的教学序列，按餐桌旁的规模裁剪：准备信号、字母顺序、课程结构，以及每一步配套的免费可打印练习纸。

## 你的孩子准备好了吗？（通常在7～8岁）

等这三个信号，大致按重要性排序：

1. **印刷体书写已基本自动化**——孩子写字不再一笔一笔「画」。在还没站稳的印刷体上叠加连笔，只会混成一团糊；
2. **精细动作的耐力**——能写满一整行，握笔不会越攥越死（铅笔测试：握笔放松，能有一根手指从下面轻轻滑过去）；
3. **孩子想要「大人的字」**——把连笔字包装成密码或超能力，最容易让孩子上钩；当作补课就没戏了。

7岁满怀热情地开始，胜过6岁满腹抗议地硬上。连笔字不用抢跑——它只是漫长童年里一个为期两个月的小项目。

## 按这个顺序教字母（而不是字母表顺序）

连笔字母共享笔画，所以要按「家族」来教——每个新字母都是昨天那个字母的小小变形：

- **第1～2周——椭圆族**：*c → a → d → g → o → q*。一个圆圈，六种出口。孩子会在这里第一次「啊哈」：*a* 不过是把 *c* 收了个口；
- **第3周——波浪族**：*i → t → u → w → e*，接着写几个真实的小词：*it, at, wet, tie*。第一次连笔就发生在这一周——值得办个小小的仪式；
- **第4周——拱形族**：*n → m → h → b → r → p*，以及单词 *him, ham, man, run*；
- **第5周——环圈和其余字母**：*l, f, k, j, s, v, x, y, z*；
- **第6周起——孩子的名字与大写字母**：收获的一周。先教8个最常用的大写字母（*C, L, M, N, S, T, J, R*），再写孩子自己的名字。

连接规则要早讲、讲明白：小写字母在基线上「握手」，但 **o、b、v、w 结尾偏高**，通常不和下一个字母握手。学会了这一点的孩子，就绕开了自学连笔字最大的挫败感。

## 10分钟一节课（每周三次）

1. **热身（2分钟）**：写一行本周家族的笔画——斜坡、拱形或波浪；
2. **描红（3分钟）**：把当天的字母或单词输进[连笔字书写生成器](/cursive)，打印出来，让孩子照着范字描——铅笔压在印好的字母上，同时把每个字母的名字念出声；
3. **临写（3分钟）**：眼睛盯住范字，在[三线可打印练习纸](/printable-paper)的下一行徒手写出同样的词。要写名字，[名字描红生成器](/name-tracing)能生成一张练习纸：范例行印成深色，描红行是浅灰色；
4. **一个亮点（2分钟）**：让孩子圈出自己写得最好的字母。到此收尾——永远不要以纠错结束一节课。

每周留一份写上日期的样本。六周后，把第一张和最后一张并排一放；看得见的进步，才会让孩子主动要求继续练。描红那一步，[连笔字练习纸生成器](/cursive-worksheets)能把任何词表——本周的字母家族、一个名字、一个拼写单词——变成打印出来就能描的练习纸。

## 毁掉家庭连笔课的错误（来自见过太多翻车现场的老师）

- **从大写字母开始**——大写字母最不统一、装饰性最强，也是让孩子最快说出「我做不到」的一条路；
- **一周只练一次、一次30分钟**——动作记忆靠短而频的练习来巩固，长课练出来的主要是疲劳；
- **上课期间不停纠错**——把反馈留到「圈出最好的字母」那一刻，以及下一节课的目标里；
- **口径不一**——学校教 D'Nealian 体，家里的范字却是另一路，那就在家里选定一种，保持一致。（我们生成器里的字体是日常手写风格，不是课程授权字体——练流畅度足够接近了，这一点我们一开始就说清楚。）

## 大家还在问

- **孩子几年级学连笔字？** 传统上是2～3年级；在恢复了连笔教学要求的20多个州，教学分布在1～6年级，通常只是点到为止。
- **该让孩子同时学印刷体和连笔体吗？** 不要——先学印刷体，直到基本自动化（通常7岁以后），再把连笔叠上去。
- **孩子学会连笔字要多久？** 按每周三次、每次10分钟的节奏，大多数孩子能在6～8周内写全所有小写字母，外加自己的名字。
- **孩子不肯练怎么办？** 把任务缩小——描两个词就收工——再让他们自己挑练习词（自己的名字、宠物的名字、一个笑话）。抗拒通常说明课程拖得太长，或者纠错太多。
