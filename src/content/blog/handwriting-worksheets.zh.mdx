# 手写练习纸怎么排:今晚做好一周的五张

周日晚上九点,打印机是你和周一早晨之间唯一的障碍。[手写练习纸生成器](/handwriting-worksheet-generator)把这件事变成五分钟的活:输入单词,选好行高,打印 PDF。页面打开时已经预填了星期词表,所以最省事又正确的做法,就是把那一版直接打印当周一的。

这是我给家长和布置晨间任务的老师的做法:今晚一次坐下来把五张都做好,别让一周的琐事替你做决定。

## 四步做好一张练习纸

1. 打开生成器,输入词表——一行一个单词,或一行一个短句。词表第一遍印成深色范字供抄写,后面的每一行都是浅色虚线描红。机制就这么简单,而且是对的:孩子先抄一遍,再把同样的词描四到五遍。
2. 选行高。5–6 岁用幼儿园档,7 岁以上用二年级档。学龄前档留给非要参与进来的 4 岁孩子——给他们写自己的名字,先别写字母表。
3. 深色示例行保持开启。那是孩子的视线在虚线行写飘之后会回去对照的一行。
4. 下载 PDF,按实际尺寸打印。US Letter 或 A4,看打印机吃什么。

输入的内容不会离开浏览器,所以全班同学的名单和拼写词表一样安全。

## 各年龄段写什么

| 年龄 | 纸上写什么 | 你在防的坑 |
| --- | --- | --- |
| 3–4 岁 | 只写自己的名字,一个词,学龄前档。字母可以等。 | 让 3 岁孩子描字母表,学会的只是在点上乱涂。 |
| 5–6 岁 | 本周绘本里的 3–5 个词,要短。 | 新词太多,描红变成没有读音的形状拷贝。 |
| 7 岁以上 | 一行一个短句——书里的事实、周末的计划。 | 这个年龄还列纯单词清单,练习就成了惩罚。 |

句子比看上去重要。一个孩子连写七天"The fox ran to the log",到周五就拥有了十一个词和一个句号。

## 周一到周五,五份词表

| 星期 | 词表 |
| --- | --- |
| 周一 | 星期词——打开页面就填好了 |
| 周二 | 周一绘本里的 3–5 个词 |
| 周三 | 颜色词和数词:红色、橙色、三、八 |
| 周四 | 一句关于周三那本书的话,一行一句 |
| 周五 | 孩子自己挑五个词,然后在空白纸上自由写 |

周五是收成日,需要另一种纸。描红纸写完后,换[可打印练习纸](/printable-paper)——干净的横线纸,没有范字——让孩子想写什么写什么。描红四天的全部意义,就在于第五天谁也不用描。

## 如果纸只写了一半

写一半没关系。任务是抄一行深色的、描两行虚线的;今晚做到了,这张纸就算完成。握笔攥成拳头就换蜡笔——点不在乎用什么描。而且要在孩子还想再来一张的时候停:生成器九十秒就能印出明天的纸,没有理由省着用。

如果抗拒其实来自词本身——读都读不懂的词谈不上"拥有"——就把词表缩成同一词根的一小组:cat、hat、sat。同一张纸,同样的行。

## 这些纸做不到什么

字体是 Patrick Hand,一款开源印刷体手写字体,不是学校的教学规范体——个别字形会和墙上的字母表略有差别。没有编号笔顺箭头,一个从下往上写 l 的孩子会继续从下往上写;那要靠看着示范纠正,不是练习纸的工作。至于名字——一个名字单独一页、按年级行高的三线格,是[姓名描红生成器](/name-tracing)的正职。同一份词表的连笔版,在[连笔字练习纸](/cursive-worksheets)生成器。
