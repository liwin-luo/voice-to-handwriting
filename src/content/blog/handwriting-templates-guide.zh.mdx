# 手写模板库:6 个场景,选一个就能写

「打开工具 → 面对空白纸张 → 不知道写什么」——模板库就是为这个瞬间准备的。每个模板 = 一段场景文案 + 一套配套的手写样式(字体、纸张、墨色、对齐),选一个、改几个字、导出。

## 六个场景速览

| 模板 | 适合 | 样式搭配 |
| --- | --- | --- |
| 情书 | 说不出口的话 | 行书 + 信纸 + 蓝黑墨 |
| 道歉信 | 认真认错 | 楷书 + 信纸 + 纯黑 |
| 感谢信 | 帮过你的人 | 行书 + 信纸 + 蓝黑墨 |
| 生日祝福 | 寿星朋友圈 | 楷书 + 白纸 + 朱红,居中 |
| 教师节 | 谢师恩 | 楷书 + 信纸 + 纯黑 |
| 新年祝福 | 跨年发图 | 楷书大字 + 白纸 + 朱红,居中 |

![模板库页面](/blog/templates.png)

## 为什么模板自带样式

我们实测下来,文案对了但样式不对,出来的图还是"不对味":道歉信用草书显得轻浮,生日祝福用黑色墨少了喜气。所以每个模板把字体、纸张、墨色、对齐、仿真度都配好了——你要做的只有把称呼和落款改成自己的。

## 怎么用

1. 在[模板库](/templates)选一个场景;
2. 预览页能看到手写效果,点「使用此模板」;
3. 文字自动进入编辑器,随意修改,右侧样式也能继续调;
4. 导出 PNG 发给对方,或导出 PDF 打印。

## 一点建议

模板是起点不是终点:把里面「朋友」「老师」改成真实称呼,加一件只有你们知道的小事,手写的价值才真正兑现。
