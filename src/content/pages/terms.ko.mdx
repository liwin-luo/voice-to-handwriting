# 이용약관

시행일: 2026-10-06. 본 사이트를 이용하면 아래 약관에 동의한 것으로 간주됩니다.

## 1. 서비스 안내

본 사이트는 무료 음성→손글씨 문서 도구를 "있는 그대로" 제공하며, 서비스 중단 없음이나 인식 결과의 완전한 정확성을 보장하지 않습니다.

## 2. 허용되는 이용

생성된 이미지와 문서는 카드, 편지, 다이어리, SNS 이미지, 필기 정리 등 개인적 목적으로 사용할 수 있습니다.

## 3. 금지되는 이용

- 타인의 필적 위조 또는 사칭, 사기·권리 침해 목적의 사용
- 법령이나 타인의 권리를 침해하는 콘텐츠 생성
- 출력물을 실제 사람의 손글씨라고 주장하여 상업적으로 기만하는 행위

본 도구의 출력은 "손글씨 스타일 렌더링"이지 실제 필적이 아닙니다. 서명이나 법적 문서 등 실제 필적이 필요한 경우에는 직접 작성해 주세요.

## 4. 지식재산권

- 생성 결과에 포함된 텍스트의 권리는 사용자에게 있습니다
- 사용 글꼴은 SIL OFL 오픈소스(마산정, 룽창, 류젠마오차오, Caveat)입니다
- 사이트의 인터페이스, 코드, 브랜드는 본 사이트에 귀속됩니다

## 5. 면책 조항

서비스 이용 또는 이용 불가로 인한 직접·간접 손해에 대해 본 사이트는 책임지지 않습니다. 음성 인식 결과는 참고용이므로 사용 전 확인해 주세요.

## 6. 약관 변경

약관은 변경될 수 있으며, 변경 시 본 페이지에 공지합니다.
