# このサイトについて

「Voice to Handwriting」は無料のウェブツールです。マイクに向かって話すと音声がリアルタイムで文字起こしされ、本物らしい手書き風の文書として表示。ワンクリックで PNG 画像や PDF に書き出せます。

## なぜ作ったのか

手書きのカードやメモ、SNS 用の手書き風画像が欲しくても、入力してレイアウトするのが面倒。世の中の手書きツールはどれも「入力」から始まりますが、話す方がalways速い。音声入力と手書きレンダリングを一体化したのは、このツールだけです。

## プライバシーがデフォルト設計

- 入力した文字や書き出しファイルはブラウザ内で処理され、サーバーには送信されません。
- 音声認識はブラウザの Web Speech API を利用:Chrome / Edge は Google の音声サービス、Apple 端末の Safari は Apple のサービスを使います。この工程は当サイトを経由しません。
- フォントや用紙の設定はローカルの localStorage にのみ保存されます。

詳しくは [プライバシーポリシー](/privacy) をご覧ください。

## このガイドの執筆デスク

ガイドは 5 つの執筆デスク(ペンネーム)が担当しています:教室の実践、大人の練習、科学解説、カードと手紙、ツールそのもの。デスクは編集部の視点を示すもので、特定の個人を表すものではありません。
