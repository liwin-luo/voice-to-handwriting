# 개인정보 처리방침

시행일: 2026-10-08 · 본 방침은 사이트 이용 시 데이터 처리 방식을 설명합니다.

## 1. 수집하지 않는 데이터

- **텍스트 내용:** 입력되거나 음성 인식된 텍스트는 브라우저 메모리와 localStorage에만 존재하며(기록에 저장한 내용도 기기에만 보관됨) 본 사이트 서버로 전송되지 않습니다.
- **내보낸 파일:** PNG / PDF는 브라우저가 로컬에서 생성합니다.
- **계정:** 계정 시스템이 없으며 가입이 필요 없습니다.

## 2. 음성 데이터의 제3자 처리

음성 인식은 브라우저의 Web Speech API로 제공됩니다.

- 데스크톱 Chrome / Edge: 음성은 Google의 음성 인식 서비스에서 처리되며 [Google 개인정보 보호정책](https://policies.google.com/privacy)이 적용됩니다.
- Apple 기기의 Safari: Apple의 음성 인식 서비스가 처리합니다.

이 단계는 본 사이트 서버를 거치지 않습니다. 완전한 로컬 사용을 원하면 텍스트 입력을 이용해 주세요.

## 3. 로컬 스토리지

아래 데이터는 모두 브라우저에만 저장되며 기기를 벗어나지 않습니다. 브라우저 데이터를 삭제하면 모두 제거됩니다:

- **표시 설정:** 글꼴·용지 등 옵션(`vth-prefs`);
- **기록:** 기록 기능을 사용하면 저장한 텍스트가 기기 내(`vth-history`)에 보관되며, 기록 페이지에서 개별 또는 전체 삭제할 수 있습니다;
- **쿠키 선택:** 쿠키 배너에서의 선택(`vth-consent`).

## 4. 로그와 통계

본 사이트는 제3자 호스팅 사업자(Vercel)를 통해 제공되며, 페이지 전달과 어뷰징 방지를 위해 표준 요청 로그(IP 주소, 브라우저 유형 등)가 처리됩니다. 또한 쿠키 없이 방문자를 식별하지 않는 집계 통계만 수집하는 Vercel Web Analytics를 사용합니다. 이 데이터는 광고에 사용되지 않습니다.

## 5. 쿠키와 제3자 광고

무료 운영을 위해 Google AdSense 등 제3자 광고 네트워크를 사용합니다. 이들은 쿠키로 맞춤 광고를 표시할 수 있습니다. [Google 광고 설정](https://adssettings.google.com/)에서 관리하거나 브라우저에서 서드파티 쿠키를 비활성화하세요.

## 6. 미성년자

본 사이트는 일반 사용자를 대상으로 하며, 14세 미만 아동의 정보를 의도적으로 수집하지 않습니다.
