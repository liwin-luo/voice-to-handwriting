# プライバシーポリシー

発効日:2026-10-08 · 本ポリシーは、本サイト利用時のデータ取り扱いを説明するものです。

## 1. 収集しないデータ

- **テキスト内容:**入力・音声認識された文字はブラウザのメモリと localStorage にのみ存在し(履歴に保存した内容も端末内のみ)、当サイトのサーバーには送信されません。
- **書き出しファイル:**PNG / PDF はブラウザがローカルで生成します。
- **アカウント:**アカウント登録はありません。

## 2. 音声データの第三者処理

音声認識はブラウザの Web Speech API により提供されます。

- デスクトップ Chrome / Edge:音声は Google の音声認識サービスで処理され、[Google のプライバシーポリシー](https://policies.google.com/privacy) が適用されます。
- Apple 端末の Safari:Apple の音声認識サービスが処理します。

この工程は当サイトのサーバーを経由しません。完全にローカルで使いたい場合は、文字入力をご利用ください。

## 3. ローカルストレージ

以下のデータはすべてブラウザ内に保存され、端末の外に出ることはありません。ブラウザデータの消去で全て削除されます:

- **表示設定:**フォント、用紙などのオプション(`vth-prefs`);
- **履歴:**履歴機能を利用した場合、保存したテキストは端末内(`vth-history`)に保存され、履歴ページから個別または一括で削除できます;
- **Cookie の選択:**Cookie バナーでの選択結果(`vth-consent`)。

## 4. ログと統計

本サイトは第三者のホスティング事業者(Vercel)により配信されており、ページ提供と不正利用防止のため標準的なリクエストログ(IP アドレス、ブラウザ種別など)が処理されます。また、Cookie を使わず訪問者を特定しない集計のみを行う Vercel Web Analytics を利用しています。これらのデータは広告には使用しません。

## 5. Cookie と第三者広告

本サイトは無料運営のため Google AdSense などの第三者広告ネットワークを利用します。これらの事業者は Cookie でパーソナライズ広告を表示する場合があります。[Google 広告設定](https://adssettings.google.com/) で管理するか、ブラウザでサードパーティ Cookie を無効化できます。

## 6. 未成年者

本サイトは一般向けで、14 歳未満の児童から意図的に情報を収集しません。

## 7. ポリシーの変更

重要な変更は本ページで告知し、発効日を更新します。
