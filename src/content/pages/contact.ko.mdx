## 자주 묻는 질문

### 음성 인식이 반응하지 않아요

데스크톱 Chrome / Edge를 사용하고, 마이크 권한을 허용하고(주소창 왼쪽 아이콘), 시스템 마이크를 확인하세요. 다른 브라우저에서는 직접 입력해 주세요.

### 인식된 텍스트에 오류가 있어요

왼쪽 텍스트 상자에서 바로 수정하세요. 용지의 손글씨가 실시간으로 업데이트됩니다.

### 내보낸 PDF가 열리지 않아요

브라우저를 최신 버전으로 업데이트하고 다시 시도하세요. 여러 페이지 내보내기 시 모든 페이지가 생성될 때까지 기다려 주세요.

### 비즈니스 문의

광고, 브랜드 제휴, API 연동은 이메일에 "비즈니스"라고 명시해 주세요.
