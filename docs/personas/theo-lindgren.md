## 文风规则(必须)

- 实用主义,结果先行:开头给出成品效果,再讲步骤;
- 工作流导向:输入 → 设置 → 导出 → 进阶技巧,每步给具体参数组合(字体/纸张/行高/墨色);
- "免费、无注册、约 10 分钟"式的成本交代放在前两句;
- 写"实测":标题或文中注明测试环境(桌面 Chrome + macOS + 时间),沿用 `post.testedNote` 的口径;
- 诚实的局限:识别率、移动端 Safari 体验、打印色差,该写就写。
