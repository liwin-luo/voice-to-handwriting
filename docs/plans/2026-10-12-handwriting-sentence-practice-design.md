# 单句练习纸

- 日期:2026-10-12
- 状态:已落地
- 登记:`docs/us-seo-content-plan.md` §二十

成人写下自己真正要写的一句,这次只练一项,印一张纸。写完三行就停。下次打开,同一句只留空白行再写一遍。

语音工作台继续服务贺卡和配图,不改。本页不上传照片,不给字打分,不把笔迹做成字体。

## 谁在用

成年人。字要给教授、同事或自己下周的笔记看。已经会写字母,练姓名描红和字母表没有用。

不是学龄前家长,不是要一张「看起来像手写」的图的人。

## 页面

路由 `/handwriting-sentence-practice`。8 语言。收在 `/tools` 练习纸分组,页头下拉不单列。

主词 handwriting sentence practice。H1 与 title 用这一句。不承接 improve handwriting adults(那是 `how-to-improve-handwriting-adults`)、name tracing、cursive worksheet generator、daily cursive handwriting practice。

窄屏顺序与现有练习纸相同:句子、本次练什么、左手、预览、下载;字号和墨色收在「更多」。宽屏左栏控件、右栏纸。

### 句子

一个输入框。空着时纸上画当前语言的一句成人例句,输入框本身保持空。英文例句:Please read this note.

只保留第一句。以 `.` `!` `?` `。` `！` `？` 断开,后面的丢掉,并在控件旁说明只印了第一句。

必须能放进一行。拉丁文超过 80 个字符、CJK 超过 40 个字符时,预览不画纸,提示缩短。不缩字、不换行、不分页。

麦克风是次按钮,复用现有 Web Speech API。不支持时只留输入框。这一页的主操作是打字。

### 这次练什么

四选一,默认「大小」。一次只能选一项。

| 选项 | 纸上多出来的线 | 范字 |
| --- | --- | --- |
| 大小 | 基线 + 中线(字高的一半)。不画顶线和降部线 | 见下方字体 |
| 斜度 | 一组平行斜线,相对竖直面向右偏 15° | 见下方字体 |
| 间距 | 每个空格处一条短竖线,标在基线上。字母不加框 | 见下方字体 |
| 印刷体 | 只有基线 | 锁定 Patrick Hand,花体开关关掉且不可开 |

「大小」同时管字高和是否贴线。Wes Morales 自查表里的「基线」和「大小」都进这一项,不另做一张几乎相同的纸。

间距只认空格。没有空格的句子(整句 CJK)仍可选择此项:纸上照印这句话和基线,不画竖线,控件旁说明词距需要空格。

字体默认 Patrick Hand。另有一个「花体范字」开关,打开后改用 Sacramento。选项为「印刷体」时该开关关闭并禁用。两款都是站内已有 OFL 字体,不新增字体文件。

行高用连笔练习纸的大行 / 普通 / 小行,不用学前、幼儿园年级标签。

墨色和纸底沿用描红页的色块。站点水印默认关,下载按钮上方可开。

纸型跟随现有语言默认:英文 US Letter,其余 A4。

### 一张纸的五行

1. 实心范字
2. 同一句的虚线
3. 空白,带当前这一项的线
4. 空白
5. 空白

纸面底部用界面字体印一行小字:写完这三行就停。这行不是练习字。不另做计时器。

左手开关:红边距改到右边。只有选了「斜度」时,斜线改为面向左偏 15°。其余选项只改边距。文案写明这是少让手抹到字,不是唯一正确的左手姿势。

下载 PDF 和 PNG,与描红页相同。文件名 `handwriting-sentence-practice`。

### 下次再写

只在用户下载 PDF 或 PNG 时写入一条本地记录,键名 `vth-sentence-practice`。字段:句子、选项、是否左手、是否花体、行高、下载时间。新的下载覆盖旧的。不存图片。

再次打开本页时,若记录存在,控件上方显示上次的选项和日期,以及一个「再写一遍」。按下后:句子和选项恢复,实心行和虚线行去掉,只留三行空白和同一套线。记录保留,直到下一次下载。

站点看不到用户用笔写下的字。再写一遍是一张空白纸,不是前后对比打分。

## 文案

用户可见字符串进 `messages/*.json`,8 个语言同一个 PR。命名空间 `sentencePractice`。FAQ 走 `ToolFaq`,页面上看见的问题和 JSON-LD 一致,三条:

1. 这张纸会给我的字打分吗?不会。选一项,印出来自己写。
2. 为什么只有三行?写久了手会握紧,三行就停。
3. 范字是我的笔迹吗?不是,是字体。

禁止出现医疗、书写障碍诊断、性格分析、作业代写。

## 逻辑边界

句子截断、是否放得进一行、五行里哪几行有范字、边距在左还是右、斜线方向,做成纯函数,放在 `src/engine/sentencePractice.ts`,测试在同目录的 `sentencePractice.test.ts`。渲染沿用描红的画布,不把这些判断写进组件。

落地时同步 `docs/ARCHITECTURE.md` 的页面地图和 `src/app/sitemap.ts` 的 `PATHS`。

## 不做

- 上传照片、自动打分、笔迹对比图
- 把本人的字做成字体
- 计时器、账号、后端
- 新的字母表、姓名描红、词表或每日花体
- 幼儿园三线格(已在 `/printable-paper`)
- 改首页语音工作台
- 性格测验改成书写诊断

## 验收

1. 英文页输入 Please read this note.,默认「大小」:一行实心、一行虚线、三行空白,能看见基线和中线,底部有停笔那一句。
2. 改成「斜度」后中线消失、出现向右的斜线;打开左手后边距在右、斜线向左。
3. 「间距」在空格处有短竖线;贴一整段时只留第一句并有说明。
4. 超过 80 个拉丁字符时不画出纸。
5. 下载后再打开,能「再写一遍」,纸上只剩三行空白。清空站点数据后该按钮消失。
6. `/zh` 打开无英文残留,语言切换后仍在本页。
7. `npm test` 通过,其中包含上面纯函数的用例。
