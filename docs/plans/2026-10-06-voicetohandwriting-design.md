## 1. 产品概述

用户在网页上说话 → 语音实时转文字(可编辑)→ 以逼真手写风格渲染在纸张上 → 导出 PNG/PDF。

**差异化**:市面上所有文字转手写工具(texttohandwriting.com、HandtextAI、萝卜工坊等)输入方式均为打字/导文件,本产品是唯一以语音为入口的一体化工具,且语音能力来自浏览器原生 API,零成本。

**目标场景**(营销定位):手写贺卡/情书/道歉信、自媒体手写文案配图、手账。**明确避开**"代写作业"叙事(伦理与舆论风险)。

**目标用户**:自媒体创作者、普通用户(低频高情感价值场景)、教师。

## 2. 总体架构(三期演进)

```
一期:Next.js 纯前端 SPA(SSG 首页)+ 无后端
      语音 = Web Speech API(浏览器原生,免费、流式、自带标点)
      渲染 = DOM + CSS 逐字抖动      导出 = html-to-image + jsPDF
二期:+ /api/transcribe(Vercel Route Handler,云端 ASR 代理)
      + MDX 内容页(SEO)+ 广告位
三期:仍无传统后端(笔迹预设/端侧 ASR/动画导出均在浏览器完成)
```

部署在 Vercel:免费、自动 HTTPS(Web Speech API 的硬性要求)、git push 即部署。

**国内可达性(二期决策点)**:`vercel.app` 默认域名在国内基本不可达,绑自定义域名可改善但不保证。若二期确认主攻国内流量(百度联盟需 ICP 备案),届时评估迁国内云;若主攻海外流量(AdSense),Vercel 即最优解。一期不阻塞。

## 3. 一期 MVP 设计(1 周)

### 3.1 页面布局(桌面优先,单页工作台)

```
┌────────────────────────────────────────────┐
│  Logo   [①说话] [②编辑/样式] [③导出]        │
├──────────────────────┬─────────────────────┤
│                      │  样式面板 StylePanel │
│   纸张预览 PaperView  │  · 字体:楷/行/草/英文 │
│   (手写效果实时渲染,   │  · 纸张:横线/方格/信纸/白│
│    支持多页翻页)       │  · 墨色/字号/字距      │
│                      │  · 仿真度滑杆(抖动强度) │
├──────────────────────┴─────────────────────┤
│  🎙 按住说话/点击说话  [导出PNG] [导出PDF]    │
└────────────────────────────────────────────┘
```

### 3.2 组件与模块

```
src/
  app/page.tsx                # SSG 首页(SEO meta + 工具入口)
  components/
    RecorderPanel/            # 录音+实时转写
    TranscriptEditor/         # 可编辑文本(用户修正错字)
    StylePanel/               # 字体/纸张/墨色/仿真度
    PaperView/                # 渲染引擎宿主 + 分页
    ExportBar/                # PNG/PDF 导出
  engine/
    layout.ts                 # 分页:按纸张高度/行高断页
    jitter.ts                 # mulberry32 PRNG 确定性抖动
    render.ts                 # 文本 → 字符 span 结构
    paper.ts                  # 纸张背景(CSS repeating-gradient 参数)
  hooks/useSpeechRecognition.ts
  stores/useEditorStore.ts    # Zustand 单 store
```

### 3.3 渲染引擎(核心)

- 每个字符包一层 `<span>`,随机参数:`rotate ±2°`、`translateY ±3px`、`scale 0.95~1.05`、字距 ±1px、墨色透明度 0.85~1;全部由「仿真度」滑杆整体缩放
- **确定性抖动**:每字符随机数 = `hash(全局种子, 字符全局索引)`,保证编辑某字不影响后续字符抖动、导出可复现
- 分页:按纸张可用高度累计行高断页,每页一个 `.paper` 容器
- 纸张背景:CSS `repeating-linear-gradient` 绘制横线/方格/信纸,行高对齐格线,导出时一并渲染
- 字体(全部 SIL OFL,已核实可商用):马善政(楷)、龙藏(行)、柳建毛草(草)、Caveat(英文)。**自托管**:`cn-font-split` 切片产物放 `public/fonts/`(不用 next/font/google,规避构建时拉 Google CDN 的不确定性)

### 3.4 语音识别

- `useSpeechRecognition` hook:`continuous` + `interimResults`(边说边出字);Chrome 约 60 秒自动断开,在 `onend` 中若仍处于录音态则自动重启;final 结果追加、interim 结果独立展示
- `lang = 'zh-CN'`
- 降级链:不支持 Web Speech API → 界面提示换 Chrome/Edge → 手动粘贴文本兜底(录音上传转写属二期)

### 3.5 导出

- PNG:`html-to-image`(SVG foreignObject,文字保真优于 html2canvas)逐页导出
- PDF:jsPDF 按 A4 尺寸拼页(整页位图方案,绕开中文字体嵌入 PDF 的坑)

### 3.6 数据流与持久化

一期全本地:文本、样式选择存 Zustand;用户偏好(上次字体/纸张)持久化到 `localStorage`。无任何网络请求(语音识别由浏览器实现)。

### 3.7 错误处理清单

| 场景 | 处理 |
|---|---|
| 麦克风权限拒绝 | 引导文案 + 指引浏览器设置 |
| 浏览器不支持 | 顶部提示条(Chrome/Edge 最佳)+ 文本粘贴兜底 |
| 识别中断/网络断 | 自动重启 3 次,失败后提示手动继续 |
| 字体加载失败 | 回退系统楷体并提示 |
| 导出失败 | 重试按钮;超长文本分页导出 |

### 3.8 测试策略

- Vitest 单测:分页逻辑、抖动确定性(同输入同输出、编辑不扰动)、PRNG
- Playwright 冒烟:打开首页 → mock SpeechRecognition 输入 → 渲染快照 → 导出按钮可用

## 4. 二期设计(差异化,2-3 周)

1. **逐笔书写动画**:选中文字 → 书法演示浮层;Hanzi Writer(MIT)逐字逐笔 SVG 动画,笔画数据(hanzi-writer-data,Arphic 宽松授权,覆盖 9000+ 常用简繁字)从 jsDelivr 按字按需加载;生僻字/英文整字淡入降级
2. **风格扩展**:新增 2-3 个 OFL 字体(如演示春风楷、沐瑶软笔手写体,逐个核实授权);笔迹质感:钢笔/圆珠笔/毛笔;仿真度预设三档(工整/自然/潦草);纸张加信纸、英语四线格
3. **照片合成模式**:上传笔记本照片 → 标定文本区域 → 手写文字 canvas 透视变形叠印 → 导出(对标萝卜工坊"抄完拍照")
4. **云端 ASR**:`/api/transcribe` Route Handler 代理讯飞/豆包(密钥存 Vercel 环境变量,免费额度内零成本),作为识别质量升级选项与 Firefox 降级方案
5. **SEO 内容 + 广告**:贺卡文案模板、手写教程等长尾词落地页(MDX + SSG);广告位:工具页底部 + 内容页内嵌,**导出流程中绝不插广告**

## 5. 三期设计(探索,按需逐项立项)

1. **个人笔迹**:轻量版「笔迹参数编辑器」(字宽/倾斜/连笔感/抖动指纹,存 localStorage 预设);真·手写样张生成字体(opentype.js 前端构建 TTF)列为技术验证项,不承诺
2. **端侧 ASR**:sherpa-onnx WASM 流式 zipformer(中英),离线+隐私卖点;COOP/COEP 响应头在 next.config 配置
3. **书写动画视频导出**:MediaRecorder 录 canvas 出 WebM(传播素材)
4. **英文版**:next-intl,`/en` 路由,吃 AdSense 高单价海外流量

## 6. 商业化与 SEO

- 广告网络:AdSense(海外流量,无需备案)vs 百度联盟(国内流量,需 ICP 备案)——二期前根据流量地域数据决策
- SEO 基线:SSG 首页 + 结构化 meta + sitemap;二期内容矩阵承接长尾词("手写体生成""贺卡文案""语音转文字"等)
- 转化漏斗:搜索 → 内容页/工具页 → 使用 → 导出(分享自带传播)

## 7. 风险与对策

| 风险 | 对策 |
|---|---|
| Vercel 国内可达性 | 二期决策点:自定义域名 or 迁国内云+备案 or 主攻海外 |
| 字体授权 | 只用 OFL 字体并留存授权文件;非 OFL 逐个核实 |
| "代写作业"争议 | 营销定位贺卡/信件/配图;不碰作业场景文案 |
| 浏览器兼容 | Firefox/移动端 Safari 降级提示;录音转写兜底(二期) |
| Hanzi Writer 字覆盖 | 生僻字/英文整字淡入降级 |
| Web Speech 60s 断开 | onend 自动重启 + 识别中断提示 |
