# 在线手写板

- 日期:2026-10-12
- 状态:工具与配套文章已落地。主词 online handwriting notepad。文章 `save-a-handwritten-note`(en,Theo Lindgren)

手机上自己写。写满眼前这一屏,导出 PNG。笔记、签名、涂鸦都用这一张纸。

语音工作台继续把文字排成手写字体,不改。本页不识别笔迹,不打分,不把笔迹做成字体。

## 谁在用

人在手机上,想马上写几个字或签个名,然后把图带走。桌面用同一套画面,不另做左右栏。页面壳和其他工具页一样,纸面可以单独全屏。

## 页面

路由 `/handwriting-pad`。8 语言。收在 `/tools`「写一张」一组,页头下拉不单列。

页面壳和其他工具页一样:`max-w-6xl` 里是标题、一句简介、纸面、分享条、说明、FAQ。不盖页脚,不改全站 layout。H1 在页头,服务端 HTML 里。

纸面是页内一块,大约七成视口高。点「全屏」后纸面和工具条盖住页头,占满视口,页面不滚动。能用 Fullscreen API 的浏览器同时收起浏览器边栏;拒绝时(常见于 iOS)只盖住网页。退出或 Esc 回到这一页。写的时候纸面锁住滚动和回弹(`touch-action: none`、`overscroll-behavior: none`)。

画面两层。底下是画布,只画纸和笔迹。工具条是浮在上面的 HTML,不进图片。

### 工具条

六个按钮:笔、橡皮、撤销、清空、下载、全屏。笔是默认。全屏时该按钮改成退出。

点「笔」展开三样,收在同一块里,不把工具条撑成两行:

- 墨色:站内已有的 7 个墨色色块,默认蓝黑 `#15317e`
- 粗细:三档,2 / 4 / 8 CSS 像素,默认 4
- 纸底:空白、横线、方格,默认空白。换纸不擦笔迹。格线是背景,间距 40px,颜色沿用 `engine/paper.ts` 里横线和方格的线色

橡皮粗细固定 28 CSS 像素,不跟笔粗走。

清空要再点一次才生效,点工具条以外的地方取消。不用浏览器自带的确认框。

说明和 FAQ 在纸面下面,写在服务端 HTML 里,和其他工具页同一套。说明里写明:图只留在这台设备上、刷新后还在直到清空、全屏怎么退出。FAQ 用 `PAD_FAQS`。

### 书写

一次只认一支笔(手指、鼠标或触控笔)。多出来的触点不画线。`pointercancel`(来电、手掌误触)把当前这一笔收到打断处,已经写完的不丢。

一笔是一条折线:笔或橡皮、颜色、粗细、一串点。点用相对纸面的比例(0 到 1),不记屏幕像素。落笔时,离上一个点不足 2 CSS 像素的点丢掉。

重画顺序固定:先铺纸底,再按顺序画每一笔。笔是圆头实线。橡皮用 `destination-out` 把底下的墨擦掉。撤销丢掉最后一笔再整张重画。

手机横过来时,用比例坐标按新的宽高重画,笔迹仍在这张纸里。正在画的那一笔先记 CSS 像素,抬笔时换成比例。

## 导出与本机保存

下载的 PNG 是画布,也就是能写字的那一块纸,不含按钮和页头。文件名 `handwriting-pad.png`。清晰度按屏幕像素比,最高 2 倍。导出失败时,下载按钮可再按一次。

只存当前这一张,键名 `vth-pad`。字段:笔迹、纸底、墨色、粗细。写入失败(隐私模式或配额满)时,字留在当前页,工具条旁提示这一张刷新后不会留下。清空覆盖这条记录。不做相册,不存 PNG。

## 文案

用户可见字符串进 `messages/*.json`,8 个语言同一个 PR。命名空间 `handwritingPad`。按钮都有可读名称,不只有图标。

禁止出现医疗、书写障碍诊断、性格分析、作业代写、笔迹识别、打分。

## 文章簇

未定。动工前在 `docs/us-seo-content-plan.md` 登记主词、文章簇和配套文章。登记只改文案和内链,不改本页的交互。

工具上线的同一个内容周期里要有至少一篇英文配套文章,页上至少两个站内入口。本文件不代替那次登记。

## 逻辑边界

抽点、比例坐标换算、存盘字符串的读写,做成纯函数,放在 `src/engine/pad.ts`,测试在同目录的 `pad.test.ts`。画布绘制留在组件里。

落地时同步:

- `src/lib/tools.ts`(groupWrite,不标 `nav`)
- `src/app/sitemap.ts` 的 `PATHS`
- `docs/ARCHITECTURE.md` 页面地图
- 8 个 `messages/*.json`

不新增依赖。

## 不做

- 笔迹识别、打分、笔迹生成字体
- PDF、加页、相册、上传
- 压感、形状、文字框
- 改首页语音工作台,或改全站 layout 来藏页脚
- 信纸、处方笺、节日纸、自定义背景图

## 验收

1. 页面和其他工具页一样:标题、简介、纸面、分享、说明、FAQ,页脚可见。工具条六个按钮都在,点「笔」能改墨色、粗细和纸底。全屏后纸面占满视口,写的时候页面不滚动;退出后说明和 FAQ 还在。
2. 画一笔、擦一段、撤销,擦掉的墨回来。再点一次清空后纸是空的;只点一次不清空。
3. 横线纸上的线出现在下载的 PNG 里,按钮不在图里。
4. 刷新后笔迹、纸底、墨色、粗细还在。清空站点数据后纸是空的。
5. 把视口从竖屏改成横屏,已写的笔迹仍在纸内。
6. `/zh` 打开无英文残留,语言切换后仍在本页。
7. `npm test` 通过,其中包含抽点、比例坐标和存盘读写的用例。
